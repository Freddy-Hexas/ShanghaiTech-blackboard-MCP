# 已知限制与后续方向

当前版本 0.3.1 推荐用于个人本机 STDIO 工作流。以下内容描述已实现的边界与仍需完善的项目；发布源码不代表通过官方插件上架审查或完成所有客户端的接入验收。

## MCP 协议与远程接入

| 项目 | 当前状态及影响 |
| --- | --- |
| HTTP Host/Origin | 启动配置尚未显式开启所需校验；仅回环绑定和 Bearer 令牌不代替该防护。HTTP 入口仍为实验性，不适合直接公开部署 |
| 业务错误标记 | 业务失败封装为普通结构化结果，MCP `isError` 可能仍为 false。调用方必须检查 `state`、`complete`、`warnings` |
| 工具注解 | 部分 `openWorldHint` 尚待按受限账户范围校准；批次确认会覆盖旧基线，恢复能力及 `destructiveHint` 也需进一步评估 |
| 输出 schema | 已有统一结果外壳，但 `data` 仍为通用对象，尚未为每种工具定义完整的业务字段模型 |
| 远程鉴权 | 当前固定 Bearer 仅用于个人回环服务，没有 OAuth 发现、授权流程和多用户会话路由 |
| ChatGPT / Dot | 需在目标账号和实际执行环境完成连接验证；没有随项目建立云端连接或保证所有客户端可直接安装 |
| 插件发布 | 包含本地插件清单与监控 Skill，未声明官方目录收录、审查通过或学校官方授权 |

MCP 本地通信与远程鉴权、客户端安装、后台通知是不同层面的能力，应分别验收。先使用 STDIO 能减少当前 HTTP 入口带来的额外配置。

## Blackboard 数据范围

- 主要兼容 Learn 3300.0.1 / Classic；不同版本、课程模板和权限配置仍可能有差异。
- 只操作当前账号已注册且有权限访问的课程。
- 不读取个人实际得分或提交记录，不提交作业，不查询公告。
- 评分列中的满分不是学生得分；截止时间已过不代表未提交。
- 正文日期只作证据和提醒，歧义与冲突需要回到课程页面核实。
- 普通课件仅提供内容和附件元数据；下载目前面向支持的 Classic 作业教师附件。
- 外部链接、未知页面布局和不支持的文件响应会显式报告限制。

## 自动监控

- 服务没有内部调度或消息发送能力，需要调用方安排频率和交付。
- 首次完整扫描建立基线，不报告历史内容为新事件。
- 未确认批次会重放并暂缓新扫描，调用方需要保存交付证据并正确确认。
- 扫描间短暂出现又消失的内容无法恢复。
- 相同元数据下只替换附件二进制内容，当前无法检测。
- 作业附件新增/替换不在自动监控范围内。
- 登录有效期由学校控制，周期访问不能保证永不过期，也没有自动重新登录。
- 定时任务能否执行，还取决于宿主在线、网络、文件访问和客户端工具权限。

## 本地数据与平台

Windows 是主要使用环境；POSIX 目录权限处理不等于跨平台完整验收。Windows Cookie 缓存使用当前用户 DPAPI；其他本地状态及浏览器目录不能因此视为全部加密。

下载结果属于 MCP 服务器电脑，当前没有远程文件交付服务。监控状态保留在本地，删除后无法从本工具恢复原基线和未确认批次。

## 后续方向

优先完善 HTTP Host/Origin 校验、MCP 错误标记、工具注解和具体输出模型；再按目标客户端推进私有连接、远程身份隔离及安装流程。普通课件下载、作业附件变化检测和远程文件交付可作为后续独立功能。
